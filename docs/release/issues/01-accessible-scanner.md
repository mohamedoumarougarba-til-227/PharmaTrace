# Ajouter les labels accessibles aux boutons icônes du scanner

Labels : good first issue, accessibility, help wanted.

Problème : certains boutons icônes ne décrivent pas leur action au lecteur d’écran. Périmètre : vérificateurs public/pharmacie, labels React Native et focus uniquement. Aucune modification d’Auth, RPC ou verdict.

Acceptation : actions nommées (caméra, retour, nouvelle recherche), navigation clavier cohérente sur web ; commandes publiques vertes. Joindre une vérification lecteur d’écran si disponible, sinon la signaler comme non exécutée. Données fictives, jamais le MVP.
